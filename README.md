# Disease Prediction Using Machine Learning

## Project Overview
This project predicts disease risk using Machine Learning algorithms and visualizes health insights using Power BI dashboards.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Power BI

## Workflow
Dataset
→ Data Cleaning
→ Model Training
→ Prediction
→ Dashboard Visualization
